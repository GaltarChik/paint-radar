From a pile of posts to a ranked report

Each step does one job. Cheap work goes to a cheap model; the one hard task goes to a stronger one.

Filter

No AI. The text is split at blank lines, and posts shorter than 20 characters are dropped, so no tokens are spent on noise.

    Under the hood

    One Streamlit file under 200 lines, one file of prompts, the OpenAI Chat Completions API in JSON mode.

    Prompting techniques
    TechniqueWhat it does
    Zero-shotStep 1 with instructions only: what counts as a problem, what does not.
    Few-shotThe same instructions plus four labelled examples. A switch in the app compares both.
    RoleStep 2 speaks as an experienced product analyst: concrete, no buzzwords.
    Chain-of-thoughtThe model writes reasoning before themes, so it thinks first. The reasoning is shown to the user.
    JSON outputA strict format in both steps, so the code can parse every answer.
    Parameters, and why
    SettingReason
    temperature 0Step 1 has one right answer per post, and the same post should get the same label every time.
    temperature 0.7Step 2 invents product ideas: at 0 they are generic, above 1.0 they lose focus.
    top_p 0.9Cuts the tail of unlikely words while ideas stay varied.
    max_tokens2000 for step 1 (about 50 posts), 1500 for step 2 so the JSON is never cut off.
    retries60 s timeout and 3 automatic retries for timeouts and rate limits.

    Built to fail politely

    No key, or fewer than 3 posts
    Stopped before any request, with the rule explained.
    Wrong key
    Says the key was rejected and where to fix it.
    Rate limit or no internet
    Retried three times, then a plain message.
    Unknown model name
    Shows the API error code and points to the sidebar.
    Broken JSON
    Asks the model once more before giving up.
    Answer cut off
    Detected from the finish reason, with advice to raise Max tokens.
